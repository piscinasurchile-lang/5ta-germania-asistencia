# Decisiones de arquitectura (ADR)

Los archivos de esta carpeta son **propuestas**, no decisiones aprobadas ni órdenes de implementación.

Ciclo: **Propuesto → Aceptado → Reemplazado/Obsoleto**. Solo el administrador puede aceptar decisiones que cambien datos, permisos, ODD, caché o dispositivos.

Cada ADR debe registrar contexto, decisión propuesta, alternativas, consecuencias, datos afectados y pruebas. Mantener historial; no borrar ADR reemplazados.

**Seguridad:** el responsable externo está a cargo; ver `../REGISTRO-RIESGOS-SEGURIDAD.md`. ADR 0003 queda como tema de coordinación, no como encargo de implementación.
